# CLAUDE.md

This repo is the workspace for **Nuggeting**, an organic TikTok and Reels channel starring
Nugget, a dachshund who gives ironic marketing advice.

## Keep it separate from PlanPy

- Never load the `planpy-copy` or `planpy-marca` skills in this repo, and never reuse PlanPy
  copy, personas, visuals, claims or pricing here.
- PlanPy material does not belong in this repo. If something looks like it came from PlanPy,
  flag it instead of using it.

## Where things go

- Brand facts live only in `brand/`. Read the relevant brand files before writing any copy,
  script or prompt. If a brand file is still a placeholder, ask rather than invent.
- Each recurring dog has a file in `brand/dogs/` with its locked Higgsfield IDs. Reuse those
  IDs; never re-describe a dog in prose across shots.
- One brief per piece in `content/briefs/YYYY-MM-DD-slug.md`, started from `_template.md`.
- Log every published piece in `content/published.md`.
- Keep large renders in Higgsfield; only small reference images go in `assets/`.
