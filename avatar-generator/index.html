AI Avatar Generator Identidad persistente · set de 20 imágenes individuales · listo para Higgsfield / Soul ID

listo
Estás abriendo el archivo con file://. Algunos navegadores bloquean el almacenamiento local aquí: los avatares y las imágenes podrían no persistir entre recargas. Sirve la carpeta por HTTP (python3 -m http.server) o publícala en GitHub Pages.

1 · Conexión

La clave se guarda solo en este navegador y se envía únicamente al endpoint que configures aquí. Usa una clave de proyecto con permiso limitado a imágenes.

Sin API key el sistema sigue siendo útil: puedes definir la ficha y exportar el «prompt pack» con las 20 instrucciones para pegarlas en Higgsfield, ChatGPT o cualquier otro backend.

2 · Avatares

Registro persistente. Cada avatar guarda identidad, persona, estilo, realismo, referencias maestras y prompt base — para poder regenerar siempre el mismo personaje.

3 · Ficha del avatar

El bloque de Identidad está bloqueado a propósito. Editar contexto, estilo o realismo no toca la identidad; editar la identidad crea una revisión nueva y marca las tomas anteriores.

4 · Referencias maestras

Opcional pero muy recomendable. Con al menos una referencia, la herramienta usa /images/edits en vez de /images/generations, y la identidad se mantiene mucho mejor entre las 20 tomas. La primera referencia marcada como principal se envía siempre.

5 · Set de 20 tomas

Cada toma se guarda como un archivo independiente (avatar_r1_01_closeup_front_neutral.png). El prompt prohíbe explícitamente collages, rejillas, dípticos y texto en la imagen.
